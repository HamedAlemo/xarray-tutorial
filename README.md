# Xarray for Geospatial Data Processing
This repository contains an introduction to `xarray` for geospatial data processing in Python. This is part of the course on [Advanced Geospatial Analytics with Python](https://hamedalemo.github.io/advanced-geo-python/intro.html) taught since Fall 2023 at Clark University. 

## Requirements

You need to use Pixi to install the local environment and run the notebooks in this repository.


## Instructions

```
pixi run jupyter lab
```

- If Jupyter Lab doesn't open automatically, copy the Jupyter Lab url and paste it in your browser. 
- Open `notebooks/xarray_fundamentals.ipynb` and follow the instructions. 
- Open `notebooks/xarray_advanced.ipynb` and follow the instructions.
